JILANI CHICKEN PAKODI QR VIDEO LANDING PAGE

1. Put your final video file in this folder and name it exactly: promo.mp4
2. Optional: add a poster image named poster.jpg (shown while the video loads).
3. Open index.html locally to preview.
4. Before publishing, edit index.html and replace the Instagram link href="#" with your actual Instagram profile URL.
5. Upload this folder to a static website host (for example Netlify Drop or GitHub Pages).
6. Once the site has its public URL, create the QR code using that URL. Scanning will open this page directly.

Autoplay note: browsers may block autoplay with sound. This page attempts muted autoplay; if blocked, it shows a Tap to Play button. Viewer can turn sound on using video controls.
